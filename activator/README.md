# مساعد التفعيل (ActivatorHelper.exe)

## التحميل
من صفحة **Releases** في المستودع ← `ActivatorHelper (latest)` ← حمّل `ActivatorHelper.exe`.

## الاستخدام
1. شغّل `ActivatorHelper.exe` واضغط **📂 فتح ملف إكسل**.
2. اضغط **🎯 تحديد حقل البحث** ثم ضع مؤشر الماوس فوق حقل «بحث عن مشترك» في برنامج الاشتراكات لمدة 4 ثواني (مرة واحدة فقط، يُحفظ).
3. اختر اللون (الافتراضي: **أخضر**).
4. اضغط على أي اسم ← يُكتب تلقائياً في حقل البحث ويُضغط Enter، ويُعلَّم الاسم بـ ✔.

- زر الماوس الأيمن على اسم: إلغاء/وضع علامة ✔.
- يمكن اختيار كتابة **اسم الاشتراك** (مثل kat-1-3-10) بدل الاسم إذا كان البحث به أدق.
- الألوان تُقرأ من خلفية خلية الاسم (أو أي خلية في الصف، أو لون الخط).
